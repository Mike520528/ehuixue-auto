## 3. 数据模型

课程学习页是 Vue2 SPA，所有状态在：

```js
document.querySelector('#app').__vue__.$data
```

| 字段 | 含义 | 备注 |
|---|---|---|
| `partinfo` | 课程节点树 | 递归要**同时**走 `n.children` 和 `n.leaf`，只走一个会漏节点 |
| `record[task_id].cumulative` | 视频已看秒数 | 服务端回写的值 |
| `ptmap[task_id].cw_length` | 视频总秒数 | 判断完成：`cumulative >= cw_length` |
| `taskStartTime` | 本次上报要带的 starttime | 直接从 `$data` 取 |
| `studied.progress` | 总进度百分比 | |
| `studied.ave_video/ave_test/ave_exam` | 视频/练习/考试平均分 | |
| `studied.num_comtest/num_comexam` | 已交练习/考试份数 | |

节点字段：

- `task_id`：数字。**比较时统一 `String()`**，否则 `===` 会失败
- `task_type`：`video` / `practise` / `exam`
- `about_id`：题卷的 eid（练习和考试才有）
- `deep`：层级，上报视频时要带
- `tasklock`：`0` 表示已解锁

## 4. 接口

全部在页面上下文里 `fetch`，带 `credentials:'include'`，自动复用 cookie。

### 4.1 刷视频

```
POST /index/study/study_recording
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
X-Requested-With: XMLHttpRequest

position=0&taskid=<task_id>&isover=1&deep=<deep>&starttime=<taskStartTime>&timer=999
```

关键在 `isover=1&timer=999`：服务端据此认为这段视频看完了，把 `cumulative`
直接累加到 `cw_length` 之上。**不需要真的播放**，也不消耗带宽。

返回体里的 `data` 是服务端回写的最新 `record`，要刷回 `vm.$data.record` 才能立刻读到新进度。

### 4.2 进卷

```
GET /index/study/joinquiz?eid=<eid>
→ {"status":100,"data":{"seid":...}}
```

`status != 100` 说明进不去（没解锁 / 已过期 / 需要重试）。

### 4.3 拉卷面

```
GET /index/study/quizscore?eid=<eid>&seid=<seid>
→ HTML
```

题目全在这份 HTML 里，每道题一个 `<table class="layui-table tableone" id="exam<qid>">`。
`parse_quiz.py` 就解析这个结构。

### 4.4 交卷

```
POST /index/study/examsheet
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
X-Requested-With: XMLHttpRequest

temp=0&eid=<eid>&seid=<seid>&answer=<URL-encoded JSON>
```

`answer` 是 `{qid: {ans, qtype, qid}}` 的 JSON 串，`ans` 形如 `"A"` / `"A,C"` / `"1"`（判断题）。
返回里含「提交成功」即成功。

## 5. 卷面 HTML 结构

```html
<table class="layui-table tableone" id="exam246499">
  <tr><td>...</td><td>题干</td></tr>
  <tr><td>A</td><td><input type="radio" name="sq_246499" value="A"></td></tr>
  ...
</table>
```

- `id="exam<qid>"` → qid
- `name="answer[<qid>]" attr1="<qtype>"` → qtype：`1` 单选、`2` 多选、`3` 判断
- 单选/多选：`name="sq_<qid>"` / `name="mq_<qid>"`，`value` 是选项字母
- 判断：`name="pd_<qid>"`，`value` 是 `1`/`2`，`title` 是选项文字

## 6. 踩过的坑

1. **URL 变了别重开页面**：切任务调 `vm.viewtask(node)`，URL 不动，登录态不丢。
2. **页面停错地方就没有数据**：必须停在 `/index/study/index?cid=..`，别的页面 `$data.partinfo` 是 undefined。
3. **视频锁着刷不动**：`tasklock != 0` 时 `study_recording` 无效。reload 会更新解锁状态；真锁着（未到开放时间）只能等。
4. **答案表按 qid 索引**，和课程绑定。换 cid 就全失效。
5. **同一份卷子重复交会覆盖成绩**，别反复跑。
6. **判断题型 qtype 是 `3`**，不是 `2`——`2` 是多选。
7. **Windows 中文输出乱码**：`set PYTHONIOENCODING=utf-8`。
